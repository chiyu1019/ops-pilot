# Kafka 消费积压处理方案

## 现象
消费者组 Lag 持续增长，下游数据延迟。

## 排查步骤
1. 用 `kafka-consumer-groups --describe` 查看各分区 Lag 分布
2. 判断是否分区倾斜（单分区 Lag 远高于其他）
3. 检查消费者实例数量与分区数的关系（消费者数 > 分区数无意义）
4. 检查消费逻辑耗时：单条处理慢或存在同步阻塞调用

## 常见原因
- 消费者处理逻辑过慢（数据库慢查询、外部接口超时）
- 分区数不足，并行度受限
- 消费者频繁 rebalance（session.timeout.ms 与 max.poll.interval.ms 配置不当）
- 上游流量突增

## 处理建议
提升并行度与分区数、批量消费、异步化处理、优化下游依赖，必要时临时扩容消费者实例。
