# CPU 告警阈值配置规范

## 适用范围
本文档规定监控系统 CPU 相关告警的阈值配置标准，适用于所有业务线与基础设施。

## 阈值分级
| 级别 | 阈值 | 持续时间 | 通知方式 |
|------|------|----------|----------|
| P3 | 70% | 10 分钟 | 邮件 |
| P2 | 80% | 5 分钟 | 企业微信 |
| P1 | 90% | 3 分钟 | 电话 |

## 配置方式
在 Prometheus 规则文件中定义 `expr: avg(rate(node_cpu_seconds_total[5m])) by (instance) > 0.8`，
并通过 Alertmanager 的 route 配置按 severity 分发。

## 调整流程
阈值调整需提交变更单，经 SRE 负责人审批后在灰度环境验证 3 天方可生效。

注意：本文档只说明阈值与配置方式，不包含故障排查步骤。
